# ArtifactGuide

This directory contains the reviewer-facing version of the artifact evaluation
rubric used in the paper.

It is organized as a compact operational guide rather than as a paper draft or
design archive.

## Suggested Reading Order

1. `rubric_overview.md`
2. `badge_rules.md`
3. `dimensions.md`
4. `representative_workflow.md`
5. `intervention_levels.md`
6. `evidence_levels.md`
7. `examples/`

## Purpose

ArtifactGuide is intended to help reviewers understand:

- what the rubric evaluates
- how evidence is interpreted
- how badges are derived
- what counts as reviewer intervention
- what kinds of evidence are sufficient for Functional and Reusable judgments
