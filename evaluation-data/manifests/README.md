# manifests

Compact suite-level metadata for the 60-artifact evaluation set.

Included files:

- `final60_gold_summary.csv`: adjudicated outcome summary for the sampled 60
  artifacts
- `final60_artifact_access_manifest.csv`: public access links for the same 60
  artifacts
- `final60_quickstart_manifest.csv`: a one-case public manifest used by the
  reviewer-facing quick start in the top-level README

The access manifest is included instead of redistributing the full downloaded
artifact payloads. This keeps the submission compact while preserving the
reviewer's ability to inspect the public artifact sources corresponding to the
sampled cases.
