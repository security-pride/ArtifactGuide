# evaluation-data

This directory contains compact, anonymized data files used to support the
paper's evaluation section.

Only paper-facing summaries and minimal case-level support tables are kept
here. The `manifests/` subdirectory additionally provides:

- a public access manifest for the 60 evaluated artifacts;
- a compact gold summary for those 60 cases; and
- a quick-start manifest for one reviewer-facing real case used in the README.
